# Native Launcher Migration Plan

## Objective and completion rule

Deliver an independently branded, fully native Rust Minecraft launcher that preserves the Modrinth App’s supported behavior and familiar interface while reusing Theseus. The native executable must not embed or depend on Tauri, Vue, JavaScript, Electron, or a WebView. A feature is complete only when its native UI is implemented, uses real backend/API behavior, works on supported operating systems, and has interaction evidence. Compilation alone does not establish parity.

This plan supplements `../MIGRATION.md`, which remains the chronological implementation log. The launcher must continue to identify Modrinth accurately where it is the authentication provider, API, or pack format; that service naming is not launcher branding.

## Current implementation constraints (2026-11-21)

- Keep the custom Rust renderer built on `winit` and `softbuffer`; do not replace it with Iced or Slint. Continue extracting route panels and reusable drawing/layout primitives into small modules.
- Keep steady-state process memory at or below the requested 60 MiB target. Bound image caches and decode concurrency, and avoid loading full-resolution imagery unless a screen needs it. This is a target that still needs runtime profiling before it can be claimed as achieved.
- Current UI image budgets: instance icons 2 MiB, browse/gallery images 5 MiB, screenshot thumbnails 4 MiB, skin previews 256 KiB; one image decode runs at a time and image readers cap decoded allocation at 16 MiB. Tokio is limited to two async workers and two blocking workers. Revisit these limits only with measured RAM data.
- Support Windows and Linux with both Wayland and X11. Winit's default Linux features enable both backends; CI must continue compiling the Windows and Linux targets.
- Treat Horizon as a separate game target with its own installation/content rules. Java mod JARs do not run in Horizon; integration should use Horizon's launcher/registry or import workflow for supported data/assets and keep ordinary Java instances unchanged.
